# 💪 Brogram – 30-Day Workout App

Brogram is a modern React app designed to help users follow a 30-day workout program with ease. Track your exercises, log weights, and mark workouts as complete — all with a clean, interactive interface.

---

### 🚀 Key Features

- 📅 Daily Workout Tracking – Push / Pull / Legs rotation
- 🏋️ Warm-up & Main Exercises – Log sets, reps, and max weights
- ❓ Exercise Descriptions – View helpful details in a modal popup
- 💾 Progress Persistence – Saves completed workouts automatically in localStorage
- 📱 Responsive UI – Works smoothly on desktop & mobile

- 💻 JavaScript (ES6+)
- 🎨 CSS / Flexbox / Grid

---

### 📝 How to Use

1. Open the app and select a day to view exercises
2. Enter weights for each exercise
3. Click **✅ Complete** to mark the workout as done
4. Click the **❓ question mark icon** to see exercise details
